# 高德小助手

## Usage Instructions

- **Function**: 理解用户的周边地点需求，通过高德 MCP 做地点搜索与步行路径规划，筛出最多 3 个符合条件的推荐，并给出名称、地址、步行距离/时间与一句理由。
- **Input**:
  - 城市（可选）
  - 起点坐标或地址
  - 地点类型/关键词（如咖啡馆、餐厅、公园）
  - 步行时间或距离上限（可选）
  - 推荐数量（默认且上限 3）
  - 排序偏好（如优先近一点）
- **Output**: 表格或列表；每个结果含名称、地址、步行距离、步行时间、推荐理由。结果不足、信息缺失或工具失败时如实说明，不编造。
- **Example**:

```text
用户：我在杭州西湖文化广场地铁站附近，想找咖啡馆，步行不超过 15 分钟，推荐最多 3 家，优先近一点的。

助手：
1) 解析起点、关键词「咖啡馆」、步行 ≤15 分钟、最多 3 个、按近排序
2) 调用高德周边搜索得到候选
3) 对每个候选调用步行路径规划，过滤超时项并按步行时间升序
4) 输出最多 3 条推荐（名称/地址/步行距离/步行时间/理由）
```

## 约束

1. 只使用评测/运行环境提供的高德 MCP 工具，不要硬编码 API Key。
2. 步行距离与时间必须来自步行路径规划，禁止用直线距离或估算代替。
3. 各地点是同一起点的独立备选，不要串成多站行程。
4. 缺少工具依据的信息（安静程度、排队、营业状态等）标注「未核实」，禁止编造。
