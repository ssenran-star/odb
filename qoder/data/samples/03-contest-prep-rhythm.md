# 初赛节奏与资料整理

练习素材，非正式官方文档。把公开赛程和自己的整理习惯记在一处，方便以后检索。

## 公开赛程摘记

第六届 OceanBase 数据库大赛围绕 seekdb、PowerContext 和 AI 生态创新出题。公开赛程里，线上报名到 2026-10-19，初赛是 2026-10-19 到 2026-11-11，决赛和答辩在 12 月中旬。Qoder 是本届战略技术支持方之一，Qoder 赛道的代码在 Qoder IDE 里写，站点用 Qoder Sites 发布。

站点验收要能打开公开链接，访问范围是任何人可访问。只停在预览页不算发布完成。

## 笔记从哪来

导入来源就三类：

1. 自己写的备赛 markdown，例如混合检索和 pyseekdb 连接这两篇。
2. 语雀专栏里摘下来的段落，保存成 `.md` 或 `.txt`，文件名写清主题。
3. seekdb、pyseekdb README 里抄下来的短片段，只保留和本项目有关的接口说明。

每份摘录在正文开头注明「摘自何处」。知识库展示命中时要带上来源路径，这样摘录和原文笔记不会混在一起。

## 复习进度以后再记

哪篇已经看过、哪条命中还要回看，可以以后交给 PowerContext 保存。这一阶段先把导入、混合检索和来源片段做稳。搜「备赛口令」时，应命中混合检索那篇笔记里的口令句，而不是本篇的赛程摘记。
